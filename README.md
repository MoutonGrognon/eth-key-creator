# Description

A script to generate ETH keys without having to create an account on yet another third party platform. 

# Requirements

[Cargo](https://doc.rust-lang.org/cargo/getting-started/installation.html)

# Usage

`cargo run`

expected output example (Do not use the private key displayed in the example) :

Make multiple backup copies of the private key generated and store them in different physical locations to reduce the risk of losing your ETH.
